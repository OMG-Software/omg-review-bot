Drop a skill .zip here (anywhere on this page) or choose a file:

A .zip with the whole skill (its SKILL.md and reference .md/.txt files) is installed into the bot's skill folder, replacing the current skill. The folder holding SKILL.md becomes the skill, so a repository's Download ZIP from GitHub works as is. A single SKILL.md replaces just that file. You can also point Settings → Skill folder at a folder on disk, such as a git clone, and manage it yourself; an upload never overwrites a git clone. Changes take effect on the next review.
