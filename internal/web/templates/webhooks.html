Webhooks

{{if .D.On}}

GitHub sends events to {{.D.URL}}. Each delivery is checked against the webhook secret; the bot then acts on it straight away and, while deliveries keep arriving, polls GitHub only every {{secs .D.Interval}} as a safety net ({{if .Status.WebhooksActive}}receiving now; last delivery {{agoT .Status.LastWebhook}}{{else}}no delivery in the last 24 hours, so it polls at the normal interval{{end}}).

In the GitHub App's settings, set Webhook URL to the address above, the same secret, and subscribe to the events Pull request, Pull request review, Pull request review comment, Pull request review thread, Issue comment and Repository. Installation events are always sent.

{{else}}

Webhooks are off: no webhook secret is set, so deliveries are refused and the bot polls. Set one in Settings → Sign-in and webhooks.

{{end}}
