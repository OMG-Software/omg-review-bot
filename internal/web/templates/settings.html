Settings

GitHub App

Create a GitHub App for your org (Org settings → Developer settings → GitHub Apps → New). Repository permissions: Pull requests: Read & write, Contents: Read-only, Metadata: Read-only. Organization permission: Members: Read-only (so sign-in can tell who administers an organization). Generate a private key. Organizations then install the App themselves.

Sign-in and webhooks

People sign in with the same GitHub App. In the App's settings set Callback URL to {{.D.CallbackURL}}, then copy its Client ID and generate a client secret. For webhooks, tick Webhook → Active, set Webhook URL to {{.D.WebhookURL}} and use the same secret as below. Without webhooks the bot polls, which works with no public address.
